# WellSpent help

> *Welcome, adventurer. Eight quests to a budget you share.*

WellSpent Budget is a budgeting app you share. Run the money for your home and your business together, and everyone sees the same numbers.

It's an early test version. Some things aren't built yet, and some things may break.

WellSpent runs on a Mac, an iPhone or a Linux computer. Each page has the steps for all three.
