# Copy and paste

Every field in WellSpent takes a paste: an email, a password, the code WellSpent emails you, or an invite link.

- **On a Mac:** Command-V pastes, Command-C copies, Command-X cuts, Command-A selects all, and Command-Z undoes. They're in the **Edit** menu too.
- **On an iPhone:** touch and hold a field, then tap **Paste**. **Copy**, **Cut** and **Select All** are in the same menu.
