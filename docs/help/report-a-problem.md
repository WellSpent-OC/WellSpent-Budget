# Report a problem

Write to **dev@wellspent.space**. It helps to say:

- whether you were on a Mac, an iPhone or Linux,
- what you were doing,
- what you expected,
- what happened instead,
- and a screenshot, if you can.

If you test through TestFlight on a Mac, you can also select WellSpent Budget in the TestFlight app and click **Send Beta Feedback**.

Never send a password or a code. Don't send a statement file unless we ask for one, because it has your bank details.
