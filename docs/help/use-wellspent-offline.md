# Use WellSpent offline

WellSpent keeps your budgets on your Mac, iPhone or Linux computer, so it keeps working with no internet. Changes you make offline wait, and go out when you're back online.

With no internet, a sync stops after about 30 seconds and says it couldn't reach the server. It tries again later. Press **Sync** to try again right away. On an iPhone, pull Home down.
