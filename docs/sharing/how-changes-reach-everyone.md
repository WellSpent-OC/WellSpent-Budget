# How changes reach everyone

> *Messengers ride between your tables.*

Sync runs on its own. It runs a moment after you make a change, and every two minutes while WellSpent is open. On a Mac, it also runs when you come back to the app. Press **Sync** to run it right away.

Everyone in a shared group sees each new transaction at their next sync, with the name of whoever added it.
