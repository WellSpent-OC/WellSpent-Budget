# Side quest: Rename a group

> *Every party deserves a good name.*

**Before you start:** you need the Manage level or higher.

1. ![A hand right-clicks the group's name in the sidebar](../assets/shots/rename-a-group-1-mac.svg)
   Right-click the group's name in the sidebar.

2. ![A hand picks Rename](../assets/shots/rename-a-group-2.svg)
   Pick **Rename…**

3. ![A hand types a new name in Name](../assets/shots/rename-a-group-3.svg)
   Type a new name in **Name**.

4. ![A hand presses Save](../assets/shots/rename-a-group-4.svg)
   Press **Save**.

   > You see the new name in the sidebar, in capital letters.

## On an iPhone

1. ![A thumb holds the group's name on Home](../assets/shots/rename-a-group-iphone-1.svg)
   Touch and hold the group's name on Home.

2. ![A thumb taps Rename](../assets/shots/rename-a-group-iphone-2.svg)
   Tap **Rename**.

3. ![A thumb types a new name in Name](../assets/shots/rename-a-group-iphone-3.svg)
   Type a new name in **Name**.

4. ![A thumb taps Save](../assets/shots/rename-a-group-iphone-4.svg)
   Tap **Save**.

## On Linux

1. ![Press ⋯ beside the group's name in the sidebar](../assets/shots/rename-a-group-linux-1.svg)
   Press **⋯** beside the group's name in the sidebar.

2. ![Pick Rename](../assets/shots/rename-a-group-linux-2.svg)
   Pick **Rename…**

3. ![Type a new name in Name](../assets/shots/rename-a-group-linux-3.svg)
   Type a new name in **Name**.

4. ![Press Save](../assets/shots/rename-a-group-linux-4.svg)
   Press **Save**.

   > You see the new name in the sidebar, in capital letters.
