# Contributing

Thank you for wanting to help.

**A signed contributor agreement comes first.** The app is also sold through the App
Store, which the GPL alone does not allow for code written by someone else. So before
a pull request from outside the project can be merged, its author signs an agreement
that lets the project ship that code under these licenses and in the App Store. Open
an issue first and ask for it.

**Every change goes through a pull request.** Nothing is pushed straight to `main`.
A pull request merges only when every CI check passes and a review has approved it.

**Write tests that fail without your change.** A fix comes with a test that fails on
the code before it and passes after it.

**Use plain words** in code comments, commit messages and pull requests, and keep
real people's names out of tests and examples.
